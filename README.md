## ✨ 프로젝트 소개

### 🌟 제목
<h2>
    <a href="https://github.com/java-MoA-org/back">
        커뮤니티 & 중고거래 & 실시간 메시징 플랫폼 "MoA"
    </a>
</h2>

### 🔎 주요 기능
- **회원 관리**
  - 회원가입 / 로그인 (JWT 인증)
  - 카카오 OAuth2 로그인
  - 프로필 수정 및 관심사 설정
- **게시판 & 피드**
  - 게시글 작성, 수정, 삭제
  - 댓글, 좋아요 기능
  - 태그/검색 기능
- **일상(Daily)**
  - 짧은 피드 형식의 게시물
  - 좋아요 및 댓글
- **중고거래(UsedTrade)**
  - 상품 등록 / 관리
  - 거래 상태 변경, 좋아요
- **메시징**
  - 1:1 채팅, WebSocket 실시간 읽음 처리
  - 이미지 전송
- **알림 시스템**
  - 댓글/좋아요/팔로우 등 실시간 알림
- **이미지 업로드**
  - 프로필/게시글 이미지 관리
- **뉴스**
  - Jsoup 기반 뉴스 크롤링

## 🤝 협업 방식

1. PR(Pull Request) 작성 후 코드 리뷰 진행
2. 배포용 product 브랜치와 merge용 main 브랜치를 따로 진행
3. 주 2회 오프라인 회의 진행 및 코드 리뷰

- **코드 리뷰**: 리뷰어 피드백 반영 후 재승인 절차 거침
- **회의 방식**: Discord/Notion 활용하여 진행 상황 공유

## ✔ 컨벤션

### 📍 코드 컨벤션
- Java Code Conventions 준수
- 클래스/메서드: PascalCase
- 변수/메서드 파라미터: camelCase
- 상수: UPPER_SNAKE_CASE
- import 순서: Java → 외부 라이브러리 → 프로젝트 내부
- 메서드 간 한 줄 공백 유지
- 주석: Javadoc 형태 권장
- 들여쓰기 : 2칸
